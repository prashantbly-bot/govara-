Platform Overview
The current frontend architecture uses modular control sections while keeping Backend and Database authority separate. STEP 27 provides the single consolidated API boundary. Customer registration is exposed through STEP 28 and communicates only through the consolidated API.
26A — System Configuration Platform identity and system-level configuration controls.
26B — User & Role Control Roles, permissions and access control configuration.
26C — Business Policies Fare, charges, discounts, KYC and business policies.
26D — Operations Control Booking lifecycle, duty, dispatch and operational controls.
26E — Financial Control Financial safety boundary and controlled financial configuration.
26F — Documents & KYC Document handling, KYC workflow, validation and verification controls.
26G — Audit & Monitoring Audit events, monitoring, security and integrity controls.
