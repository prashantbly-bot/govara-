Architecture Boundary

Frontend is a control interface only. Backend remains authoritative for business, financial and persistent data operations.

26A — System Configuration

Central system-level configuration. This is the master configuration layer for GoVara.

Important: 26A controls system configuration only. Business rules belong to 26C, operational controls to 26D, financial authority remains backend-side, and audit records are handled by 26G.
1. System Identity
Production environment selected. This is a configuration declaration only. Real-money and real-payment capabilities remain blocked until authoritative backend controls are implemented and verified.

3. System Lifecycle & Operating Behaviour
Platform Enabled Master switch for the GoVara frontend control layer.
New Registration Allows new user registration when enabled.
Booking System Global booking capability switch.
Notification System Global notification capability switch.
Maintenance: when System Status is MAINTENANCE, operational actions are treated as restricted by the frontend. Backend remains authoritative.
Suspended: when System Status is SUSPENDED, operational actions are considered blocked by the frontend. This does not create backend authority.
4. Social Welfare — System-Level Control
Social Welfare is a cross-module capability. 26A controls the master system availability; detailed eligibility, benefit and business rules belong to 26C.
Social Welfare System Master enable/disable switch for welfare capability.
Welfare Administrative Control Allows Administrator Control Center to configure welfare system state.
Welfare Audit Required Welfare configuration changes must generate audit events.
